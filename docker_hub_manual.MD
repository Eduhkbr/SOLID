# Distribuição opcional das imagens

A aula padrão valida tudo localmente. Publicar exige conta e repositório de destino próprios.

Depois de construir e testar, confira a imagem com docker compose images. Autentique no registry autorizado e atribua uma tag própria antes do push. Não copie um namespace de exemplo como se fosse seu. Não inclua .env, credenciais ou dados reais.

O workflow de publicação é manual e exige a opção publish habilitada; não demonstra implantação real.
